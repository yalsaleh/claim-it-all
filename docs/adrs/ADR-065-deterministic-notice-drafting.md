# ADR-065 — Deterministic drafting

| Field | Detail |
|-------|--------|
| Status | Accepted |
| Date | 2026-07-29 |

**Context:** AI must not be required to produce a usable notice for CI.

**Decision:** Deterministic assembler fills core sections from templates + approved facts + requirement snapshot + verified deadline. Generator version is recorded. Usable English and Arabic fixtures ship with the package.

**Consequences:** CI proves drafting without commercial AI.
