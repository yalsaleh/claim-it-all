# ADR-045 — Recalculation and supersession

| Field | Detail |
|-------|--------|
| Status | Accepted |
| Date | 2026-07-20 |

**Decision:** Trigger-date corrections, calendar supersession, configuration supersession, or applicability changes require a mandatory recalculation reason, a new calculation version, and supersession of prior tracked deadlines. Completed deadlines are not silently reopened.
