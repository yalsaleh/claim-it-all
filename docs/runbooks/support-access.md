# Runbook — Support access

## Grant
1. Open ticket with tenant, scope, duration ≤ 8h, justification.
2. Obtain approver ≠ requester (PILOT/PRODUCTION).
3. Issue support grant/session distinct from user cookies.
4. Perform least-privilege diagnosis; avoid document body access unless scoped.
5. Revoke grant at completion; confirm audit events present.

## Forbidden
Enable fake providers; dispatch notices; confirm legal state; break-glass via product UI.
